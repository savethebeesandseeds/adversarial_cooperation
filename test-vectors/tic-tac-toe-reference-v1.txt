Adversarial Cooperation: Tic-Tac-Toe Positive Reference Vector Version 1
========================================================================

Purpose
-------

This deterministic teaching vector follows one semantically valid, non-losing
X policy through the recursive checker, fixed-DAG checker, emitted Core-X
Boolean circuit, and disclosed Bind opening. Every layer receives the same
19,683 policy bytes.

The vector is reproducibility evidence for those executable paths. It is not
evidence of commitment hiding or binding, zero knowledge, extraction,
authorship, chronology, future policy use, or production security. The policy
and nonce are intentionally public in this test vector.

Policy
------

Game and policy version: 1
Claimant role:          X (1)
Initial board index:    0, u16 big-endian

The policy is the exact output of:

    ac_ttt_build_reference_policy(AC_TTT_ROLE_X, &policy)

It is Canonical Policy Version 1: a complete 19,683-byte table generated by
deterministic minimax/backward induction with ascending-cell tie breaking.
Required X-turn entries contain the selected legal cell; every other entry is
0xff. The recursive and fixed-DAG checkers both return NON_LOSING, and the
emitted Core-X circuit returns acceptance bit 1.

Reproduction
------------

Run the normal randomized teaching mode:

    make -C demostrations demo_ttt_bind

Run the deterministic reference mode:

    make -C demostrations demo_ttt_bind \
        TTT_BIND_ARGS=--reference-vector

Only the explicit reference mode is expected to reproduce the fixed digest
and byte-identical output. The default mode correctly uses fresh randomness.

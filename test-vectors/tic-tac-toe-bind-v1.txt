Adversarial Cooperation: Tic-Tac-Toe Bind Profile Version 1
================================================================

Purpose
-------

This vector fixes the external policy-commitment byte contract. It is evidence
that two independent implementations produced the same deterministic digest.
It is not evidence of hiding, binding, zero knowledge, extractability,
authorship, or production security.

Payload
-------

payload length: 19,687, u64 big-endian

The first four payload bytes are:

    01 01 00 00

They mean game version 1, claimant X, and empty-board index zero.

For policy byte index i in [0, 19682]:

    policy[i] = (17 * i + 3) mod 256

This deliberately synthetic table need not be a legal policy. The vector tests
commitment framing; the separate Core relation tests policy legality/non-loss.

Independent reproduction
------------------------

Python 3 standard-library `hashlib.blake2b(..., digest_size=32)` produced the
digest above from the exact byte sequence described here. Python is a
verification tool for this vector, not a project runtime dependency.

The application must enforce session uniqueness and meaningful round
allocation. Merely hashing these fields does not itself prevent replay.

\chapter{Telling an Adversary It Is Wrong}
\label{short:telling-an-adversary-it-is-wrong}

Can secret information help us tell an adversary it is wrong, without
requiring it to reveal its own secret? A useful warning might let the party correct its course
while retaining information it has reason to protect.

Begin by asking who holds the secret and who should learn the warning. Name
the mistake precisely. Consider what the warning itself would disclose, even
if no one spoke the secret aloud.

The original note leaves these roles unsettled. They must be understood
before choosing a construction. The question is still open; no private
warning protocol is supplied here.

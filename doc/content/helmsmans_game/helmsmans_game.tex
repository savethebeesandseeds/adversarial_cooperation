\chapter{The Helmsman's Game}
\label{chap:helmsmans-game}

\researchstatus{Early game definition}{The working title also recorded two
Chinese characters, code points \texttt{U+6DF1 U+8BAE}. Their intended reading
and translation require author review.}

The Helmsman's Game is a diplomatic conversational game that aims to helm the
destiny of people without breaking the foundations and agreements of the
participating parties. Its moves, information, victory condition, and failure
states remain to be defined.

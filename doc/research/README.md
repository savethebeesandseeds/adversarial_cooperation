# Research records

This folder holds the research program's working records. The evolving
[white paper and its editable source](../white-paper/README.md) live separately
in `doc/white-paper/`.

Start with the [research charter](RESEARCH_CHARTER.md) and
[edition map](EDITION_MAP.md). Current technical status is recorded in the
[claim ledger](CLAIM_LEDGER.md), [assumption ledger](ASSUMPTION_LEDGER.md),
[open problems](OPEN_PROBLEMS.md), and [roadmap](ROADMAP.md).

- [plans/](plans/) records decisions, work performed, and verification evidence.
- [archive/manuscript/](archive/manuscript/README.md) preserves earlier author
  writing and the former standalone poker note, with original paths recorded.
- [REPOSITORY_LAYOUT.md](REPOSITORY_LAYOUT.md) explains current source/output
  locations and how to locate material cited at old paths.
- [organization-moves.json](organization-moves.json) records the artifact cleanup;
  [structure-moves.json](structure-moves.json) records the subsequent author-directed
  consolidation into `doc/`, `code/`, `web/`, and `.local/`.
- [tools/check_repository_layout.py](tools/check_repository_layout.py) verifies
  preserved file bytes against the local pre-move inventory.

Completed plans and the original repository audit retain historical paths and
commands. They are evidence of their recorded revision, not current build
instructions. Follow the root README and folder guide for present commands.

# Earlier manuscript versions

These files preserve earlier author writing. They are historical source, not
current protocol specifications or material included by the book build.
All ten backups differ from the active manuscript; several preserve questions
and original wording not present in current chapters. Their bytes were retained
unchanged during the repository organization on 2026-09-12.

The former standalone poker note is also retained here. Its statements belong
to that earlier draft; the current standalone target now uses the canonical
chapter in `doc/content/poker_without_revealing_the_cards/`.
